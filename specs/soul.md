# soul

the declaration of the mind: one file — `~/cyb/soul` today — defining how the agent processes an ask. which model [[cy/specs/soma|soma]] loads, which dialect it speaks, what it may do unasked, what it must always refuse. [[cy/specs/com|com]] reads the soul on every question; [[cy/specs/ward|ward]] enforces what the soul permits.

part of the [[cy/specs/anatomy|anatomy]] (identity). the soul is small on purpose: it is one of the four things you back up (name · soul · vault seed · log) — carry them to any machine and the robot resurrects
