# name

the agent's name is not a setting — it is a resolver over the graph. the name lives in the [[cybergraph]] as a naming link, owned like a token, resolving to the neuron wherever it runs. lineage: the [[moon-passport]] names of the bootloader era (47,837 of them) port into the soft3 genesis and become the first names.

name is the **who** slot of the [[cy/chroma/README|chroma]] (top-right). a name can be sold, lent or inherited — the agent survives all three; what changes hands is the pointer, not the being. [[cyb]] draws the name as the [[cyb/parts/avatar|avatar]]; headless, it is the prompt's prefix.
